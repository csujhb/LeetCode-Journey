## 力扣 763：划分字母区间 (C 语言) 学习笔记

### 1. 算法本质：贪心算法 + 双指针

这道题的本质是一个“寻找连带边界”的问题。
核心原则只有一个：**只要当前片段里收录了某个字母，这个片段的右边界就必须“延伸”到该字母在整个字符串中最后一次出现的位置。**

你可以把它想象成“连带责任”：

* 你抓了第一个 `'a'`，就必须把后面所有的 `'a'` 都抓进同一个牢房。
* 但在抓后续 `'a'` 的路上，你不可避免地会顺手抓到 `'b'` 和 `'c'`。
* 既然抓了 `'b'` 和 `'c'`，牢房的范围又得继续扩大，直到囊括所有的 `'b'` 和 `'c'`……
* **什么时候可以关上牢门（切一刀）？** 当你走到某个位置，发现里面所有犯人的“同伙”都已经在这个牢房里了（即当前下标 `i` 追上了目前需要延伸的最远边界 `right`），就可以完美切分了。

### 2. 解题两步走

* **第一步：查户口（预处理）**
遍历一遍字符串，用一个大小为 26 的数组 `last`，记录下每个字母最后一次出现的下标位置。
* **第二步：动态划界（双指针遍历）**
维护两个变量：`left`（当前片段的起点）和 `right`（当前片段必须要到达的最远终点）。
再次遍历字符串，每遇到一个字母，就去查它的“底细”，并尝试更新 `right`。当遍历的指针 `i` 走到了 `right` 时，说明当前片段已经完整，记录长度，开启下一个新片段。

### 3. 代码模板与核心注释

```c
#include <stdlib.h>
#include <string.h>

int *partitionLabels(char *s, int *returnSize) {
    int last[26] = {0};
    int len = strlen(s);
    
    // [细节] 最坏情况下每个字母都不一样，会切出 len 个片段，所以 calloc 分配 len 的大小绝对安全
    int *res = (int *)calloc(len, sizeof(int));
    
    // 1. 预处理：记录每个字母最后一次出现的下标
    // 巧妙利用 s[i] - 'a' 将字母映射到 0-25 的索引
    for (int i = 0; i < len; i++) {
        last[s[i] - 'a'] = i;
    }
    
    int count = 0;  // 记录切了多少刀（结果数组的实际长度）
    int left = 0;   // 当前片段的左边界
    int right = 0;  // 当前片段的右边界
    
    // 2. 贪心遍历：寻找切割点
    for (int i = 0; i < len; i++) {
        // 获取当前字母的最后一次出现位置
        int curLast = last[s[i] - 'a']; 
        
        // 更新当前片段必须要延伸到的最远距离
        if (curLast > right) {
            right = curLast;
        }
        
        // 当走到最远距离时，说明当前片段内所有字母在后面都不会再出现了
        if (i == right) {
            // 记录当前片段长度 (右边界 - 左边界 + 1)
            res[count++] = i - left + 1;
            // 下一个片段的起点就是当前位置的下一位
            left = i + 1; 
        }
    }
    
    // C语言接口要求：通过指针返回结果数组的有效长度
    *returnSize = count; 
    return res;
}

```

### 4. 复杂度分析

* **时间复杂度**：$O(N)$。其中 $N$ 为字符串的长度。虽然有两次 `for` 循环，但它们是平行的（独立的），总共遍历了两次字符串，所以时间复杂度依然是线性的。
* **空间复杂度**：$O(1)$（或者严谨地说是 $O(\Sigma)$，$\Sigma = 26$）。辅助数组 `last` 的大小固定为 26，不随字符串长度变大而变大。返回的 `res` 数组空间是作为输出必需的，通常不计入额外空间复杂度。

### 5. C 语言避坑指南

1. **字符到索引的映射**：在 C 语言中，一定要熟练使用 `char - 'a'` 这种技巧来代替复杂的 Hash 表计算，这在处理纯小写/大写字母题目时是“降维打击”。
2. **`malloc` vs `calloc**`：初始化结果数组时，使用 `calloc(len, sizeof(int))` 可以自动将申请到的内存清零。虽然这道题里我们会用 `count` 严格控制有效数据的读取范围，但清零的好习惯可以避免在调试时看到随机的垃圾数据。
