# 算法研读笔记：分割等和子集 (LeetCode 416)

## 一、 问题抽象与数学建模

本问题要求判定一个正整数数组是否能够被划分为两个元素和相等的子集。从组合优化（Combinatorial Optimization）的角度进行严密等价转换，该问题可映射为**判定性 0-1 背包问题（0-1 Knapsack Problem）**。

1. **可行性前置条件**：设数组全体元素之和为 $\sum_{i=1}^{N} nums[i] = S$。若 $S$ 为奇数，根据整数域的封闭性，不可对其进行二等分，直接判定为假。
2. **容量与价值映射**：若 $S$ 为偶数，设定目标子集和为 $C = \frac{S}{2}$。此目标值等价于背包的容量限制。数组中的各个元素 $nums[i]$ 既代表物品的“重量”，也代表其“价值”。核心命题转化为：是否存在一种组合，使得背包恰好被填满。

## 二、 状态空间转移分析

为了优化空间复杂度，算法通常采用一维状态压缩技术进行求解，将原本二维的状态矩阵投影至一维向量上。

定义布尔型状态向量 $dp[j]$，其语义表示：在前置决策过程中，能否从已遍历的元素中挑选出若干项，使其总和精确等于 $j$。

### 状态转移方程

对于遍历到的第 $i$ 个元素 $nums[i]$，目标容量 $j$ 的状态更新逻辑如下：

$$dp[j] = dp[j] \lor dp[j - nums[i]]$$

其边界条件初始化为：$dp[0] = \text{true}$，即容量为 0 的背包在不选择任何元素的情况下自然成立。

### 逆序遍历的理论必然性

在状态空间压缩的工程实现中，内层关于容量 $j$ 的循环**必须采取逆序遍历（自 $C$ 降至 $nums[i]$）**。
若采用正序遍历，当计算后排容量 $j$ 对应的状态时，其所依赖的前置状态 $dp[j - nums[i]]$ 可能在当前周期内已被该元素更新为 $\text{true}$。这违背了 0-1 背包中“单元素不可复用”的硬性约束，从而发生模型退化（退化为完全背包问题）。逆序遍历严格确保了无后效性与单次决策独立性。

## 三、 复杂度论证

* **时间复杂度**：$\mathcal{O}(N \times C)$。其中 $N$ 为数组基数，$C$ 为目标容量（即总和的二分之一）。该算法表现为伪多项式时间复杂度（Pseudo-polynomial time）。
* **空间复杂度**：$\mathcal{O}(C)$。仅需分配长度为 $C + 1$ 的一维状态向量。

## 四、 工业级 C 语言实现规范

在系统级编程环境下，内存的安全管理与分支指令优化至关重要。以下实现包含内存泄漏防御与分支预测优化。

```c
#include <stdbool.h>
#include <stdlib.h>

bool canPartition(int *nums, int numsSize) {
    int sum = 0;
    for (int i = 0; i < numsSize; i++) {
        sum += nums[i];
    }
    
    // 奇数直接剪枝，避免后续无效计算
    if (sum % 2 != 0) return false;

    int target = sum / 2;
    
    // 动态分配堆内存并初始化为0 (false)
    bool *dp = (bool *)calloc(target + 1, sizeof(bool));
    if (!dp) return false; // 防御性编程：校验内存分配状态

    dp[0] = true;
    
    for (int i = 0; i < numsSize; i++) {
        // 内层循环逆序遍历，严格保障 0-1 背包特性
        for (int j = target; j >= nums[i]; j--) {
            // 运用逻辑或运算符处理状态转移，减少条件分支指令
            dp[j] = dp[j] || dp[j - nums[i]];
        }
        
        // 启发式剪枝：目标状态一旦达成，终止后续冗余迭代
        if (dp[target]) break; 
    }
    
    // 结果暂存与资源释放，杜绝内存泄漏
    bool result = dp[target];
    free(dp);
    
    return result;
}
```
